# The Marquee Moon changelog

v0.3.0: Search TMDB and show release years | 2026-10-28 13:41

Category: frontend

- src/pages/Home.jsx: the search form now queries TMDB through
  searchMovies and replaces the grid with the results, with loading and
  error states. Empty queries and searches made while a request is
  pending are ignored.
- src/components/MovieCard.jsx: cards show the release year from the
  service's releaseYear field instead of the missing release_date.
- package.json, package-lock.json, README.md: version bumped to 0.3.0.

Category: tooling

- .claude/skills/prepare-commit/SKILL.md: new workflow that updates the
  changelog, version numbers and README, then proposes a commit message
  and waits for approval.
- CLAUDE.md: moved the changelog rules into the prepare-commit skill;
  commits now wait for approval.
- docs/changelog/changelog_0-x-x.txt: entries reformatted with their
  categories listed under each title.

Category: documentation

- docs/progress.md: marked the TMDB step done, set the Favorites page as
  next, and added later goals (server-side API proxy, automated tests
  with CI/CD, SEO, stronger security).
- docs/to_fix.md, docs/to_improve.md: recorded open bugs and the search
  UX issue.
- README.md: rewrote the description, Learning Goals and Future Goals.


v0.2.0: Load popular movies from the TMDB API | 2026-10-27 22:33

Category: architecture

- src/services/api.js: rewrote the TMDB client around a shared tmdbFetch
  helper (API base URL, Bearer read access token, query parameters,
  abort signal, and an error for non-OK responses). Added a toMovie
  mapper from TMDB results to the MovieCard shape, and named exports
  getPopularMovies and searchMovies.
- package.json, package-lock.json, README.md: version bumped to 0.2.0.

Category: frontend

- src/pages/Home.jsx: replaced the mock movie list with popular movies
  fetched on mount, cancelled through an AbortController on unmount.
  Added loading and error states.


v0.1.2: Backend review skill and TMDB service draft | 2026-10-27 19:24

Category: architecture

- src/services/api.js: first draft of the TMDB client with popular-movies
  and search requests. Not yet wired into the UI.

Category: tooling

- .claude/skills/backend-api-review/SKILL.md: new skill for reviewing
  backend and API code (secrets, authentication, authorization,
  validation, external API clients, endpoint design, readability and
  full-stack integration).
- CLAUDE.md: changelog entries may be split across two categories; added
  the tooling category.


v0.1.2: Marquee Moon favicon | 2026-10-27 16:38

Category: frontend

- public/favicon.svg: replaced the default Vite logo with an amber crescent
  moon, a row of marquee bulbs and a lit bulb on the warm ink tile.
- public/apple-touch-icon.png: 180px full-bleed PNG export of the favicon
  for iOS home screens and older Safari.
- index.html: linked the apple-touch-icon.


v0.1.1: Remove unused src/css folder | 2026-10-27 14:40

Category: architecture

- src/css/: deleted the six stylesheets (App, Favorites, Home, MovieCard,
  NavBar and index). Nothing imported them; styling now comes from
  Tailwind classes and src/index.css.
- package.json, package-lock.json: version bumped to 0.1.1.


v0.1.0: Marquee Moon redesign with Tailwind CSS | 2026-10-27 14:33

Category: frontend

- src/index.css: replaced the Roboto-only starter theme with Marquee design
  tokens (warm ink surfaces, paper text, marquee amber accent), DM Serif
  Display for headings, and a visible focus ring.
- src/App.jsx: page shell with a full-height layout and a centred content
  column.
- src/components/NavBar.jsx: sticky header with the Marquee Moon wordmark and
  NavLink active states.
- src/components/MovieCard.jsx: 2:3 poster cards with a labelled "Add to
  favorites" button, visible on touch and on hover or focus otherwise.
- src/pages/Home.jsx: hero with a labelled search field, results heading with
  a live count, responsive poster grid, and a no-results message. Posters are
  now imported from src/assets, so they resolve in production builds. Movie
  data is still mock.
- src/pages/Favorites.jsx: empty state with a link back to browsing.
- package.json, package-lock.json: version bumped to 0.6.0.
